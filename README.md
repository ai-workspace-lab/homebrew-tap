# ai-workspace-lab Homebrew Tap

Official Homebrew Tap for [ai-workspace-lab](https://github.com/ai-workspace-lab) macOS applications.

## Installation

```bash
brew install --cask ai-workspace-lab/tap/xworkmate
```

Or tap first:

```bash
brew tap ai-workspace-lab/tap
brew install --cask xworkmate
```

## Upgrade

```bash
brew upgrade --cask xworkmate
```
